Dense core

Types and helpers in src/dense/core that the rest of NextLA builds on.

NextLAMatrix

NextLAMatrix{T}(data::Matrix{T}) wraps a dense matrix so that LinearAlgebra.lu! on it runs NextLA's own pivoted LU (getrf2!) and LinearAlgebra.BLAS.axpy! runs NextLA's axpy!. The other LinearAlgebra.BLAS calls on it (gemv!, gemm!, trmm!, trsm!, syrk!, herk!, syr2k!, her2k!) pass the wrapped matrix to the system BLAS.

using NextLA, LinearAlgebra

A = rand(1024, 1024)
F = lu!(NextLAMatrix{Float64}(copy(A)))   # NextLA's getrf, with partial pivoting
F.L * F.U ≈ A[F.p, :]

# output

true

Machine parameters

NextLA.lamch — Method
lamch(::Type{T}, cmach) where{T<: Number}

Determines single / double precision machine parameters

Arguments

  • T : type, currently only tested Float32 and Float64
  • 'cmach' : specifies the value to be returned by lamch
- = 'E': returns eps
- = 'S': returns sfmin
- = 'P': returns eps*base

- where
	- eps = relative machine precision
	- sfmin = safe min, such that 1/sfmin does not overflow
	- base = base of the machine

Examples

julia> NextLA.lamch(Float64, 'E') == eps(Float64) / 2
true

julia> NextLA.lamch(Float32, 'S') == floatmin(Float32)
true

Usage examples

The example stands on its own and ends with a check that prints true.

Solving a system through NextLAMatrix

lu! on a NextLAMatrix returns an ordinary LinearAlgebra.LU, so \ solves with it.

using NextLA, LinearAlgebra

n = 2048
A = rand(n, n)
B = rand(n, 256)

F = lu!(NextLAMatrix{Float64}(copy(A)))   # NextLA's getrf, with partial pivoting
X = F \ B
A * X ≈ B

# output

true
