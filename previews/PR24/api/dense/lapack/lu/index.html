Pivoted LU (LAPACK style)

LinearAlgebra.lu! — Method

Computes an LU factorization of a general M-by-N matrix A using partial pivoting with row exchanges. The factorization has form A = P * L * U where P is a permutation matrix, L is lower triangula with unit diagonal elements (lower trapezoidal if m > n), and U is upper triangular (upper trapezoidal if m < n)

This is the recursive form of the algorithm.

Examples

julia> using LinearAlgebra

julia> A = rand(1024, 1024); b = rand(1024);

julia> F = lu!(NextLAMatrix{Float64}(copy(A)));

julia> A * (F \ b) ≈ b
true

NextLA.getc2! — Method

lu!(A::DLAArray{T}, ::CompletePivoting; check::Bool = true, allowsingular::Bool = false) where {T<:BlasFloat}

Computes an LU factorization with complete pivoting of the n-by-n matrix A. The factorization has the form A = P * L * U * Q, where P and Q are permutation matrices, L is lower triangular with unit diagonal elements and U is upper triangular.

Arguments

  • 'A' : matrix, dimension (n,n)
    • on entry, the n-by-n matrix A to be factored
    • on exit, the factors L and U from the factorization A = P * L * U * Q; the unit diagonal elements of L are not stored.
    • If U(k,k) appears to be less than smin, U(k,k) is given the value smin, i.e, given a nonsingular pertubed system

Examples

julia> using LinearAlgebra

julia> A = rand(1024, 1024);

julia> F = getc2!(NextLAMatrix{Float64}(copy(A)), CompletePivoting());

julia> p = LinearAlgebra.LU(F.factors, F.ipiv, 0).p; q = LinearAlgebra.LU(F.factors, F.jpiv, 0).p;

julia> UnitLowerTriangular(F.factors) * UpperTriangular(F.factors) ≈ A[p, q]
true
source
NextLA.getrf2! — Method
getrf2!(A::AbstractMatrix{T}, ipiv::AbstractVector{Int}, info::Ref{Int})

Computes an LU factorization of a general M-by-N matrix A using partial pivoting with row exchanges. The factorization has form A = P * L * U where P is a permutation matrix, L is lower triangula with unit diagonal elements (lower trapezoidal if m > n), and U is upper triangular (upper trapezoidal if m < n)

This is the recursive form of the algorithm.

Arguments

  • 'A' : matrix, dimension (m,n)

    • On entry, the m-by-n matrix to be factored
    • On exit, the factors L and U from the factorization A = P * L * U; the unit diagonal elements of L are not stored

  • 'ipiv' : dimension (min(m,n))

    • the pivot indicies; for 1 <= i <= min(m,n), row i of the matrix was interchanged with row ipiv[i]

  • 'info' :

    • =0: successful exit
    • <0: if info = -i, the i-th argument had an illegal value

    • 0: if info = i, U[i,i] is exactly zero. The factorization has been completed, but the factor U is exactly singular and division by zero will occur if it is used to solve a system of equations

Examples

julia> using LinearAlgebra

julia> A = rand(1024, 1024); B = copy(A); ipiv = zeros(Int, 1024);

julia> _, _, info = getrf2!(B, ipiv, 0);

julia> F = LinearAlgebra.LU(B, ipiv, info);   # wrap the LAPACK-style output

julia> info == 0 && F.L * F.U ≈ A[F.p, :]
true
source

Recursive and tiled LU

NextLA.lu_recursive! — Function
lu_recursive!(A::AbstractMatrix, block_size::Integer=LU_BLOCK_SIZE) -> A

Recursive unpivoted LU of a square matrix, in place: A = L * U with L unit lower triangular and U upper triangular, packed into A. The recursion splits n at the largest power of two below it (at n ÷ 2 when n is one) and factors blocks of at most block_size rows without pivoting, keeping the bulk of operations in A's precision. lu_recursive_nopiv! takes a matrix of any shape.

Warning

Unpivoted, leaves included, so the matrix must need no pivoting – a diagonally dominant one, for instance. A zero pivot throws ZeroPivotException; a small one is not checked.

Examples

julia> using LinearAlgebra

julia> A = rand(1024, 1024) + 1024I;   # diagonally dominant: needs no pivoting

julia> F = lu_recursive!(copy(A), 256);

julia> UnitLowerTriangular(F) * UpperTriangular(F) ≈ A
true
source
NextLA.lu_recursive_nopiv! — Function
lu_recursive_nopiv!(A::AbstractMatrix, block_size::Integer=LU_BLOCK_SIZE) -> A

Recursive unpivoted LU of a matrix of any shape, in place: A = L * U with L unit lower trapezoidal and U upper trapezoidal, packed into A.

Halves the columns, factors the left panel over the full height, solves for the U block to its right and updates the trailing block before recurring into it. lu_recursive! is the square-only counterpart; prefer it when A is square, and this when it is not.

Warning

Unpivoted, leaves included, so the matrix must need no pivoting – a diagonally dominant one, for instance. A zero pivot throws ZeroPivotException; a small one is not checked.

Examples

julia> using LinearAlgebra

julia> A = rand(2048, 1024); A[1:1024, :] += 2048I;   # tall, needs no pivoting

julia> F = lu_recursive_nopiv!(copy(A), 256);

julia> L = tril(F, -1) + Matrix(I, 2048, 1024); U = triu(F[1:1024, :]);

julia> L * U ≈ A
true
source
NextLA.lu_base! — Method
lu_base!(A) -> (A, p, info)

LU with partial pivoting in one work-group, in place: L (unit diagonal) and U are packed into A, and p is the row permutation as a vector, A0[p, :] == L * U. As LAPACK's getrf, info is 0 or the first k with a zero U[k, k], and nothing is thrown. On a GPU n must be at most 32.

Examples

julia> using LinearAlgebra

julia> A = rand(1024, 1024);

julia> F, p, info = lu_base!(copy(A));

julia> info == 0 && UnitLowerTriangular(F) * UpperTriangular(F) ≈ A[p, :]
true
source
NextLA.tile_lu_factor! — Method
tile_lu_factor!(A, n) -> (A, p, info)

Tiled LU with partial pivoting within each n x n tile, in place, on a GPU: L (unit diagonal) and U are packed into A, and p is the row permutation as a vector, A0[p, :] == L * U. A tile's row swaps reach the rest of its tile row as a gather of those rows. As LAPACK's getrf, info is 0 or the first k with a zero U[k, k], and nothing is thrown. The tile n must divide both dimensions and be at most 32.

Examples

GPU only (it throws ArgumentError on the CPU backend), so this example is not run as a doctest:

julia> using NextLA, CUDA, LinearAlgebra

julia> A = rand(1024, 1024);

julia> F, p, info = tile_lu_factor!(CuArray(A), 32);

julia> F = Array(F);

julia> info == 0 && UnitLowerTriangular(F) * UpperTriangular(F) ≈ A[p, :]
true
source

Usage examples

Each example stands on its own and ends with a check that prints true.

Pivoted LU of a NextLAMatrix, then a solve with several right-hand sides through the returned LinearAlgebra.LU object:

using NextLA, LinearAlgebra

A = rand(2048, 2048)
B = rand(2048, 16)

F = lu!(NextLAMatrix{Float64}(copy(A)))   # partial pivoting, computed by getrf2!
X = F \ B
A * X ≈ B

# output

true

getrf2! called directly returns LAPACK's pivot vector; laswp applies those row interchanges to the right-hand side before the two triangular solves:

using NextLA, LinearAlgebra

n = 2048
A = rand(n, n)
b = rand(n, 1)

F = copy(A)
ipiv = zeros(Int, n)
_, _, info = getrf2!(F, ipiv, 0)

x = copy(b)
laswp(x, 1, n, ipiv, 1)                  # x := P * b
x = UpperTriangular(F) \ (UnitLowerTriangular(F) \ x)
info == 0 && A * x ≈ b

# output

true

Complete pivoting with getc2!, which permutes both rows and columns, A[p, q] = L * U:

using NextLA, LinearAlgebra

A = rand(1024, 1024)
F = getc2!(NextLAMatrix{Float64}(copy(A)), CompletePivoting())

p = LinearAlgebra.LU(F.factors, F.ipiv, 0).p   # row permutation from ipiv
q = LinearAlgebra.LU(F.factors, F.jpiv, 0).p   # column permutation from jpiv
UnitLowerTriangular(F.factors) * UpperTriangular(F.factors) ≈ A[p, q]

# output

true

Unpivoted recursive LU of a diagonally dominant matrix, with leaves of at most 512 rows, used to solve a system:

using NextLA, LinearAlgebra

n = 4096
A = rand(n, n) + n * I            # diagonally dominant: no pivoting needed
F = lu_recursive!(copy(A), 512)

b = rand(n)
x = UpperTriangular(F) \ (UnitLowerTriangular(F) \ b)
A * x ≈ b

# output

true

lu_recursive_nopiv! factors a tall panel, here 4096 by 1024; L is unit lower trapezoidal and U square:

using NextLA, LinearAlgebra

m, n = 4096, 1024
A = rand(m, n)
A[1:n, :] += m * I                # needs no pivoting

F = lu_recursive_nopiv!(copy(A), 256)
L = tril(F, -1) + Matrix(I, m, n)
U = triu(F[1:n, :])
L * U ≈ A

# output

true

On a GPU the same calls take device arrays. tile_lu_factor! runs on a GPU only, with tiles of at most 32. This block is not run when the documentation is built:

using NextLA, CUDA, LinearAlgebra

n = 4096
A = rand(n, n) + n * I
dF = lu_recursive!(CuArray(A), 1024)       # the leaves go to cuSOLVER, unpivoted
F = Array(dF)
UnitLowerTriangular(F) * UpperTriangular(F) ≈ A

B = rand(2048, 2048)
dG, p, info = tile_lu_factor!(CuArray(B), 32)   # pivoting within each 32×32 tile
G = Array(dG)
info == 0 && UnitLowerTriangular(G) * UpperTriangular(G) ≈ B[p, :]
