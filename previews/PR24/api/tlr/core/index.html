Tile low-rank core

NextLA.TileLowRank, in src/tlr/core: tile low-rank (TLR) matrices, whose off-diagonal tiles are stored as low-rank factors, and their compression from dense matrices. Load it with using NextLA.TileLowRank; it is not re-exported by NextLA.

NextLA.TileLowRank — Module
TileLowRank

Tile low-rank (TLR) matrices. A TLRMatrix splits a matrix into tiles, keeps the diagonal tiles dense and stores each off-diagonal tile as low-rank factors U*V'; a CompressedFTLRMatrix stores every tile that way. Both are built by compressing a dense matrix, expanded back with uncompress!, and multiplied with TLR methods of gemm!. Opt in with using NextLA.TileLowRank; this module is not re-exported by NextLA.

Containers

NextLA.TileLowRank.CompressedFTLRMatrix — Type
CompressedFTLRMatrix

Logical-rank block-compressed storage with independently ordered factors.

Every tile of the full grid, diagonal included, is stored as factors U * V' of its own logical rank. All U factors share one packed vector and all V factors another. Build one by compressing a dense matrix, CompressedFTLRMatrix(A, tile_size; maxrank, ...), or allocate one from known ranks, CompressedFTLRMatrix(backend, T, m, n, tile_size, ranks).

Examples

julia> using NextLA.TileLowRank, LinearAlgebra

julia> using Random; Random.seed!(1);  # compression is randomized

julia> n = 1024; U, V = randn(n, 8), randn(n, 8); A = U * V';

julia> F = CompressedFTLRMatrix(A, 128; maxrank=32, tol=1e-8, rel=true);

julia> B = similar(A); uncompress!(B, F);

julia> all(==(8), ranks(F)) && norm(B - A) / norm(A) < 1e-8  # diagonal tiles too
true

NextLA.TileLowRank.CompressedFTLRMatrix — Method
CompressedFTLRMatrix(backend, T, m, n, tile_size, ranks;
           outer_order=TileRowMajor, inner_order=TileColMajor,
           rank_multiple=0)

Allocate a finalized CompressedFTLR matrix from known logical tile ranks. Physical factor widths equal the logical ranks when rank_multiple == 0 and are otherwise rounded up to that positive multiple. A regular nominal grid may have one trailing row and/or column tile.

backend is a KernelAbstractions backend such as CPU(), tile_size a tuple (bm, bn) or one integer for square tiles, and ranks a cld(m, bm) × cld(n, bn) integer matrix whose entries do not exceed their tile's dimensions. All factors start as zeros, ready to be filled in place.

Examples

julia> using NextLA.TileLowRank, LinearAlgebra

julia> backend = NextLA.KernelAbstractions.CPU();

julia> F = CompressedFTLRMatrix(backend, Float64, 1024, 1024, 128, fill(5, 8, 8);
                                rank_multiple=8);

julia> X, Y = get_factors(F, 3, 4);

julia> size(X) == (128, 5) && iszero(X) && maxrank(F) == 5 && maximum_storage_rank(F) == 8
true

NextLA.TileLowRank.TileRowMajor — Type
TileRowMajor()

Row-major traversal of the logical tile grid.

This is the default outer_order, and the only one TLRMatrix accepts. The per-tile vectors ranks(A) and residuals(A) follow the outer order, so with TileRowMajor tile (i, j) is entry (i - 1) * nt + j, where nt is the number of tile columns.

julia> n = 1024; U, V = randn(n, 8), randn(n, 8); A = U * V' + n * I;

julia> C = TLRMatrix(A, 128; maxrank=32, tol=1e-8, rel=true);

julia> r = ranks(C);  # tile (i, j) is entry (i - 1) * 8 + j

NextLA.TileLowRank.ARAConvergenceState — Type
ARAConvergenceState(backend, count)

Per-batch-member bookkeeping for the ARA loop over count members.

samples[b] is how many columns member b should draw on the next pass and is the single source of truth for whether it is still active: 0 means converged (or capped). ranks[b] is the index of the last column that carried significant energy, svec[b] the number of consecutive negligible columns seen so far, jcount[b] the columns accumulated, and rmax[b] the running maximum projected norm against which the relative test is made.

Members advance independently, so jcount is tracked per member rather than as a shared loop counter.

NextLA.TileLowRank.ara_build_basis! — Method
ara_build_basis!(ws, sample_right!; eps_rel, r_required=10, compute)
    -> (; Q, ranks, passes)

Grow an orthonormal basis for the column space of a batch of implicit operators to relative tolerance eps_rel (Boukaram, Turkiyyah & Keyes, Algorithm 2.3).

sample_right!(Y, width) must overwrite the first width columns of the m × block × count array Y with Xᵦ Ω for a freshly drawn Gaussian Ω, independently per batch member. Freshness is required because the stopping rule is the Halko–Martinsson–Tropp a posteriori bound, whose failure probability decays like 10^{-r_required} only for independent samples.

Each pass projects the block against the existing basis with two-pass block classical Gram-Schmidt, normalizes it with two mixed-precision Cholesky-QR passes, and folds diag(R) into the convergence state. A member stops when r_required consecutive columns are negligible, when potrf_batched! reports a numerically singular block, or at maxrank.

eps_rel below ara_stopping_floor is rejected rather than silently run to maxrank.

source
NextLA.TileLowRank.ara_cholesky_pass! — Method
ara_cholesky_pass!(ws, R, R_tiles; status=nothing, count=size(ws.Q, 3))

Apply one mixed-precision Cholesky-QR pass to the first count members of ws.Q. The Gram matrix and Cholesky factorization use the promoted type; the triangular solve and stored factor use the basis storage type.

ARA deliberately treats a failed Cholesky factorization as a rank signal. When provided, status receives the per-member factorization status. A zero pivot is stored as NaN, so the solve marks the columns from it on as non-finite on every backend instead of throwing, and ara_mask_breakdown! discards them.

source
NextLA.TileLowRank.ara_mask_breakdown! — Method
ara_mask_breakdown!(Y, dR, kcut, R1, status, width, floor_rel; scale=nothing) -> kcut

Discard the columns of a block that the orthonormalization could not deliver, keeping its valid prefix. R1 is the first-pass triangular factor and floor_rel the CholeskyQR2 validity threshold √u_hi; the composite factor cannot identify where the first pass became invalid.

A column is cut when its pivot is below floor_rel times the largest pivot of the block, or of scale[b], the largest projected norm earlier passes saw for member b (ARAConvergenceState.rmax). Without scale, a block of pure rounding noise, which a member that has already stopped still draws while others sample, has no large pivot to be measured against and is kept.

ara_truncate!(U, V, ranks, err_sq, Q, Z; tol, relative=true, maxrank)
    -> (; U, V, ranks, err_sq)

Optimally truncate X ≈ Q Zᵀ to per-member rank, writing U (b_m × maxrank × count, orthonormal columns) and V (b_n × maxrank × count).

tol is the Frobenius error budget, relative to each member's reference energy when relative=true. err_sq[b] is the achieved squared error; ranks[b] == maxrank indicates that the spectrum exceeded capacity.

energy[b] = ‖X‖_F² of the original operator may be supplied when known independently. The range-capture error ‖X‖² - ‖Z‖² is then included, so err_sq covers both range capture and truncation. With neither, the reference is ‖Z‖² and capture is assumed zero, which is correct when Q was built to tolerance by ara_build_basis!. capture[b], an estimate of the squared range-capture error ‖X - QQᴴX‖_F² when ‖X‖² is not known, is added to err_sq[b] only: the ranks are chosen as without it, so a zero entry leaves that member unchanged. capture may be the same array as err_sq.

Z is overwritten.

ara_update_convergence!(state, dR, eps_rel, r_required, block, maxrank)

NextLA.TileLowRank.CompressedFTLRMatrix — Method
CompressedFTLRMatrix(A, tile_size; maxrank, tol=0, rel=false, r_required=10,
                     rank_multiple=0, workspace=nothing)

Compress dense A in one adaptive pass and return finalized packed factors. rank_multiple == 0 stores exact widths; a positive value rounds each nonzero tile rank up to that multiple without changing its logical rank.

Every tile, diagonal included, is compressed with the blocked adaptive randomized range finder, which draws from the global random number generator.

  • tile_size: a tuple (bm, bn) or one integer for square tiles.
  • maxrank: required cap on each tile's rank.
  • tol: Frobenius-norm error allowed per tile, absolute, or relative to the tile's norm when rel=true. With the default tol=0 nothing may be dropped, so tiles are typically kept at rank maxrank; pass a positive tol.
  • r_required: consecutive negligible samples needed before a tile's basis stops growing.
  • workspace: an FTLRCompressionWorkspace built for the same matrix size, element type, tile size and maxrank with diagonal=:compressed, reused instead of allocating a new one.
  • outer_order, inner_order (also accepted): tile orders of the packed factors, TileRowMajor and TileColMajor by default.

Examples

julia> using NextLA.TileLowRank, LinearAlgebra

julia> n = 1024; U, V = randn(n, 16), randn(n, 16); A = U * V';

julia> F = CompressedFTLRMatrix(A, 256; maxrank=64, tol=1e-8, rel=true);

julia> B = similar(A); uncompress!(B, F);

julia> all(==(16), ranks(F)) && norm(B - A) / norm(A) < 1e-8
true

          rank_multiple=0, workspace=nothing)

NextLA.TileLowRank.FTLRCompressionWorkspace — Type
FTLRCompressionWorkspace(A, tile_size; maxrank, diagonal=:compressed,
                         block=max(min(32, maxrank), 1))

Reusable dense-to-FTLR compression storage.

There is one category per distinct logical tile shape. diagonal=:compressed includes every tile; diagonal=:dense excludes diagonal tiles so the same workspace builds the compressed off-diagonal part of a TLRMatrix.

Pass it as workspace to CompressedFTLRMatrix(A, ...) (with diagonal=:compressed) or TLRMatrix(A, ...) (with diagonal=:dense) to compress several matrices of the same size, element type and backend with the same tile_size and maxrank without reallocating the scratch; any mismatch throws an ArgumentError. Each call still returns newly allocated factors, so earlier results stay valid. block is the number of random samples drawn per step.

Examples

julia> using NextLA.TileLowRank, LinearAlgebra

julia> using Random; Random.seed!(1);  # compression is randomized

julia> n = 1024; U, V = randn(n, 8), randn(n, 8); A1 = U * V' + n * I; A2 = 2 * A1;

julia> ws = FTLRCompressionWorkspace(A1, 128; maxrank=32, diagonal=:dense);

julia> C1 = TLRMatrix(A1, 128; maxrank=32, tol=1e-8, rel=true, workspace=ws);

julia> C2 = TLRMatrix(A2, 128; maxrank=32, tol=1e-8, rel=true, workspace=ws);

julia> B = similar(A2); uncompress!(B, C2);

julia> maxrank(C1) == maxrank(C2) == 8 && norm(B - A2) / norm(A2) < 1e-8
true
